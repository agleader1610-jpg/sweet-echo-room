💡 Quick Usage Guide

  1. 1. Open Target Website: Browse to any website (e.g. ads.telegram.org).
  2. 2. Capture APIs: Check the "Captured APIs" tab to view intercepted JSON requests.
  3. 3. Edit Data: Click "✏️ Edit & Mock" on any captured response to change names, balances, views, or numbers.
  4. 4. Save & Refresh: Click Save, then refresh the target web page. Smart Path matching will keep your modified data active every time you reload!
  5. 5. Share Diagnostics: If any issue occurs, click "🛠️ Export Debug Diagnostics Log" and send us the file to fix and update the extension!
